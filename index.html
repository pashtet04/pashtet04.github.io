01 / about

About

I work with existing production systems.

Most of my work is not greenfield: clusters already run, services already have users, databases already contain data, and changes need to be safe enough for production.

I operate infrastructure, troubleshoot incidents, plan migrations, clean up delivery pipelines, improve monitoring and replace manual operational steps with documented automation.
